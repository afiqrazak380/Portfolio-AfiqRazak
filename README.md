# Afiq Razak — Portfolio

My personal portfolio website, built from scratch with vanilla HTML/CSS/JavaScript.

🔗 **Live site:** [afiqrazak-profile.netlify.app](https://afiqrazak-profile.netlify.app)

## About

This site showcases my background, certifications (IBM Back-End/Front-End
Development, Google Data Analytics, FreeCodeCamp), and project work as I
build toward a career in tech — currently focused on IT Support and
Networking (CCNA).

## Built with

- HTML5 / CSS3 (including responsive media queries)
- Vanilla JavaScript
- Hosted on Netlify

## Running locally

```bash
git clone https://github.com/afiqrazak380/Portfolio-AfiqRazak.git
cd Portfolio-AfiqRazak
open index.html   # or use a local server, e.g. `npx serve`
```
